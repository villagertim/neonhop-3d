## Running application

The existing browser tab was reloaded and autonomous supported play started; it has not been stopped or reconfigured during this handoff. Browser play state was not freshly inspected at handoff.

Start the server from the workspace with `npm start` (Python gateway; no bundling build). Restart after changing `.env`; reload the browser after source changes. Avoid launching a duplicate server on port 8000.

The active controller is `src/supportedJevAgent.js`, extending `src/jevAgent.js`. `src/candidateForecasts.js` computes exact ten-tick candidate outcomes using cloned engine state. Jev receives all five candidates, their survival/progress forecasts, and game observations. Four simultaneous questions are sent; only the Choice selects a proposed move. The existing physics shield checks it again when executed. Local control and adaptive memory operate between requests.

Requests explicitly select OpenRouter `typesafe/jev-1.13`; observed replies identified `typesafe/jev-1.13-20260917`. Both provider credentials are in the ignored `.env`; do not print or publish them. The supported controller has no alternate-model route or direct-browser provider fallback.

### Intentional pauses

The game freezes simulation while a sampled Jev request is pending. A new request becomes eligible after a two-second wall-clock gap from the preceding completion, at an idle input boundary. This keeps the request's forecasts current. The request timeout is eight seconds. Failure resumes local control and delays the next attempt for 30 seconds. Countdown and combo timing use simulation time so inference waits do not consume them.

The user noticed these pauses and was told they are intentional. Removing them requires a different scheduling/invalidation design; no such change has been implemented. Do not call this continuous moving-world Jev control.

Pause, human takeover, reset, and speed changes cancel pending decisions. The previous hybrid's three-second automatic restart after game over is restored. Hybrid high scores and learned memory were preserved.
