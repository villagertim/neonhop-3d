# Supported Jev deployment

Deployed to the local workstation at http://127.0.0.1:8000/ on 2026-09-20. The server was restarted and the existing browser tab reloaded. Autonomous supported play was started and visibly progressed to score 2,820; this is a smoke verification, not a comparative performance experiment.

## Installed behavior

The active controller is `src/supportedJevAgent.js`, extending the preserved hybrid. Local candidate forecasts are generated by `src/candidateForecasts.js`, using ten-tick deterministic engine replay with the tested survival/progress rubric. All thirty saved candidate results match the bounded experiment. Jev receives these forecasts with exact state and rules. The original safety shield evaluates its proposed move again at execution; local policy and adaptive memory remain active.

Requests explicitly select OpenRouter Jev. No second inference model participates. The four simultaneous answers are retained; only Choice directs movement. The final bounded test used one Choice question, so adding the three telemetry questions is a deployment difference rather than a newly controlled comparison.

The old 100 ms deadline would discard observed responses. This deployment instead freezes simulation during a sampled request (eight-second timeout), waits at least two seconds after completion before sampling another stable idle state, and runs local control between requests. Failed requests trigger 30 seconds of local control before retry. This is explicit frozen-time integration, not a claim that Jev meets moving-world deadlines. Original human takeover, pause, speed, reset-brain, and automatic game-over restart controls remain available.

## Verification

- 57 JavaScript and eight Python regression tests passed: [output](jev-supported-deployment-tests.txt).
- New tests cover forecast parity, frozen simulation, accepted Jev attribution, shield veto, timeout/cooldown with local continuation, takeover cancellation, and non-Jev response rejection.
- Live trace at this check: 26 Jev responses, 16 proposals executed unchanged, 10 proposals replaced by the shield, 5 captures and 0 deaths recorded since this session started. These counts continue changing while the user watches.
- Observed model: `typesafe/jev-1.13-20260917`. Logs verified explicit OpenRouter routing and five candidate forecasts per request.
- [Live session trace](jev-supported-live/1581d87e-951d-4189-a3a7-563efba0e4bd.jsonl) records requests, responses, remote applied moves, outcomes, and cumulative local/remote counters. Local moves are counted rather than individually logged. The server keeps traces private.
- Browser was left in autonomous play. No separate background evaluation or scheduled task was created.

## Boundaries

This deploys the promising tested feature into the supported game. It does not establish a full-game improvement over the earlier hybrid. The finite replay result and limitations remain in the [final test report](jev-supported-final-test/report.md). Old hybrid memory and scores are preserved; displayed lifetime streaks and highs should not be attributed to this short verification.
